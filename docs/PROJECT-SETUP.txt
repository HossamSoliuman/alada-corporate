========================================
 CORPORATE WEBSITE - SETUP & HANDOVER
========================================

This is a standard Laravel 12 website. It runs on a NORMAL web server.
No special server configuration is needed.


----------------------------------------
1. SERVER REQUIREMENTS (normal server)
----------------------------------------
- PHP 8.2 or higher (extensions: OpenSSL, PDO, Mbstring, Tokenizer, XML, cURL, GD, Fileinfo, BCMath)
- MySQL 5.7+ (or MariaDB)
- Composer
- Node.js + NPM (only needed to build the design files)
- Apache or Nginx web server

Point the web server's public root to the "public" folder. That's it.


----------------------------------------
2. INSTALLATION STEPS
----------------------------------------
1. Upload / copy the project files to the server.
2. Copy ".env.example" to ".env" and fill in your database name, user, and password.
3. Run these commands inside the project folder:

   composer install
   php artisan key:generate
   php artisan migrate --seed
   npm install
   npm run build
   php artisan storage:link

4. Open the website in the browser. Done.


----------------------------------------
3. ADMIN LOGIN & ACCESS
----------------------------------------
Admin panel URL : https://YOUR-DOMAIN/admin
Login page      : https://YOUR-DOMAIN/login

Default admin account (created automatically by step 3 above):
   Email    : admin@example.com
   Password : password

IMPORTANT: Change this password right after the first login.


----------------------------------------
4. CHANGING THE ADMIN PASSWORD
----------------------------------------
Passwords are changed from the USERS section in the admin panel:
   1. Log in to the admin panel.
   2. Open "Users" from the menu  (URL: https://YOUR-DOMAIN/admin/users).
   3. Click Edit on the user you want.
   4. Type a new password (at least 8 characters) and save.

From the same Users page you can also add new users or remove them.

Note: the default password (admin@example.com / password) is only set
once during the first install. After install, always change it here.


----------------------------------------
5. THIRD-PARTY INTEGRATIONS / SERVICES
----------------------------------------
All of these are optional and configured in the ".env" file:

- Email (SMTP)            -> MAIL_* settings
- Google reCAPTCHA v2     -> NOCAPTCHA_SECRET, NOCAPTCHA_SITEKEY
- Google Analytics 4      -> GA4_ID
- Google Tag Manager      -> GTM_ID
- WhatsApp float button   -> WHATSAPP_NUMBER

Built-in features (no setup needed): PDF export, Excel export,
SEO tags, and automatic sitemap.


----------------------------------------
6. DEPLOYMENT (updating the live site)
----------------------------------------
After uploading new code, run:

   composer install --no-dev
   php artisan migrate --force
   npm install
   npm run build
   php artisan optimize


----------------------------------------
7. BACKUP INSTRUCTIONS
----------------------------------------
Back up these two things regularly:

1. DATABASE  -> export the MySQL database (e.g. with mysqldump or phpMyAdmin):
      mysqldump -u USER -p DATABASE_NAME > backup.sql

2. FILES     -> copy the "storage/app/public" folder
                (this holds all uploaded images and files).

Keep the ".env" file in a safe place too (it has your settings).
